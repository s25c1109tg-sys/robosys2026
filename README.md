# plusコマンド

![test](https://github.com/s25c1109tg-sys/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数を足して、合計を表示します。

## 使い方

```sh
seq 5 | ./plus
# 15
```

## 必要なソフトウェア

- Python 3
- テスト済みバージョン：3.10〜3.14

## テスト環境

- Ubuntu 24.04 LTS
- GitHub Actions
